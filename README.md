**[Live site →](https://rayhe.github.io/sp500-exec-comp)**

## Data Verification Taxonomy

Every NEO row in `data/compensation.json` carries a `_total_source` label describing its audit state, assigned against the primary DEF 14A Summary Compensation Table. Buckets (as of 2026-09-24: 6,936 rows):

| Label | Meaning | Rows |
|---|---|---|
| `verified` | Components and total match the filing SCT verbatim. Includes `def14a_verified_YYYYMMDD` re-verification passes | 6,908 (99.6%) |
| `rounding` | Components don't foot the printed total by a small gap; stored verbatim | 0 (bucket collapsed 2026-09-12; 24 rows re-verified vs primary SCTs and relabeled def14a_verified_20260912) |
| `recomputed` | Filing total missing/implausible; total recomputed from components | 0 (36-row bucket eliminated 2026-09-10) |
| `component_mismatch` | The filing's own components don't sum to its printed total; stored verbatim, flagged | 28 |

Taxonomy decision (2026-09-10): 319 `verified` rows carry $1–$2 deltas between summed components and the printed total (e.g., NVDA/UBER/SOLV FY2025–2026). This is the filer's own rounded-dollar arithmetic, not a parse error, so they stay `verified` — relabeling would cut headline coverage from 99.7% to 95.7% for zero information gain.

`scripts/check_metadata_consistency.py` (pre-commit hook) asserts every metadata count equals an independent recount of stored records, so stale counts can never be committed.

Expanding the company row shows a "Smooth equity grants" toggle; when on, each NEO's stock + option awards are spread evenly across that NEO's own available fiscal years (the filing's SCT window, typically 3 years) and added back to as-filed cash comp, producing annualized totals for apples-to-apples comparison. The toggle swaps five views together: the NEO tables, trend sparklines, Pay Mix Evolution, CEO Pay Trend, and the YoY Component Waterfall ("Compensation Change Drivers") — the waterfall's smoothed variant shows deltas of smoothed totals with equity folded into "Equity (avg)" (constant across years, so it drops out as a zero delta and the smoothed waterfall reads as cash-comp drivers; e.g. WELL FY2024→FY2025 goes from Net +$800.9M as-filed to Net +$1.2M smoothed). The smoothed waterfall renders only when smoothing actually changes a CEO-year total and both CEO years have multi-year grant data. As-filed figures remain the default; smoothed figures are clearly badged and never replace stored data. NEOs with a single fiscal year on record show — (nothing to smooth).
